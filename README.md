# 提醒钟（Reminder Clock）

一个运行在 Windows 上的桌面提醒小工具：平时安静地待在系统托盘后台，
到点后弹出置顶提醒窗口，支持**单次 / 每天 / 每周**三种提醒规则，其中
“每天 / 每周”都可选择按**指定时间**或**时间段**提醒，以及延迟时间可自定义的
“稍后提醒”功能。

## 下载（不想装 Python 的话）

到 [Releases 页面](https://github.com/lcwenjie/ReminderClock/releases) 下载
最新版本的 `提醒钟.exe`，**单文件免安装**，双击即可运行，目标电脑不需要安装
Python。提醒数据保存在 exe 同目录的 `reminders.json`，连同 exe 一起拷贝就能
带着已有任务换电脑。

> Windows SmartScreen 可能对未签名的 exe 给出“未知发布者”提示，
> 点“更多信息” → “仍要运行”即可（个人项目未购买代码签名证书）。

## 功能一览

- 提醒列表管理：**新增 / 编辑 / 删除 / 启用·暂停**
- 三种时间规则，每天 / 每周下各有「指定时间」与「时间段」两种方式：
  - 单次：在某个具体日期时间提醒一次，确认后自动从列表移除
  - 每天：
    - 指定时间：每天固定时刻提醒
    - 时间段：每天在一段时间内按固定间隔重复提醒，
      例如 `08:00 至 17:30 每 30 分钟` 一次
  - 每周：勾选一周中的若干天（可多选星期），在选中的日子里提醒；
    同样可选指定时间或时间段
  - 时间段的共同约定：
    - 开始时刻即当天首次执行时间，之后按间隔递进，**含结束时刻**
      （即 08:00 与 17:30 都会提醒）
    - 当天时段结束后，顺延到下一个执行日的开始时刻；暂不支持跨天时段
      （结束时间需晚于开始时间）
- 到点提醒：置顶弹窗显示标题与内容，点“知道了”关闭
- 延迟提醒（稍后提醒）：每条提醒可单独设置延迟分钟数（默认 **5 分钟**，
  在新增 / 编辑表单里修改）；到点弹窗里也能直接改，点“稍后提醒”后按该
  分钟数再次弹出
- 单次提醒错过时间后会在列表中显示为灰色“已过期”，可手动清理
- 后台运行：程序启动后在系统托盘保留小图标
  - 托盘右键菜单：打开提醒钟 / 添加提醒 / 退出
  - 关闭主窗口（点 ×）只是隐藏到后台，**并不会退出程序**
- 关闭期间错过的**重复**提醒不会追补轰炸，下次仍按规则正常提醒

## 版本号

版本号**以时间命名**，格式为 `YYYYMMDD-HHMM`（例如 `20260914-1501`），
保存在 `core/version.py` 的 `APP_VERSION`：

- 运行时，主窗口标题栏会带上当前版本号（托盘悬停提示保持简洁，不显示版本）；
- 打包时 `build.bat` 会先把 `APP_VERSION` 自动改写为**打包时刻**的时间戳，
  因此每个发布包都带唯一、可按时间排序的版本号。

## 安装与运行

需要 Python 3.9+，然后安装两个第三方依赖（其余全部用标准库）：

```bash
pip install -r requirements.txt
```

运行：

```bash
python main.py
```

不想每次带一个黑色控制台窗口的话，双击运行或改用：

```bash
pythonw main.py
```

第一次运行会显示主窗口，之后即可通过托盘图标随时唤出。

> 提示：想开机自启，把打包好的 `提醒钟.exe`（或源码运行时的 `main.py`）
> 创建快捷方式后，放进 `Win+R` → `shell:startup` 打开的文件夹即可。

## 数据存放位置

数据文件放在**程序所在文件夹**，方便整体拷贝、U 盘便携：

```
<程序目录>\reminders.json
```

- **源码运行时**：`reminders.json`、`error.log` 放在项目根目录；
- **打包成 exe 运行时**：都放在 `提醒钟.exe` 同目录；
- 从旧版（数据在 `%APPDATA%\ReminderClock`）升级时，首次启动会自动把旧数据
  拷贝到新位置，旧文件保留不动（程序运行中只会迁移这一次）；
- 数据在**退出程序（托盘 → 退出）**时自动保存；
- 若程序在运行中遇到内部错误，会额外写一份 `error.log`（含错误详情），
  排查问题时把它发给开发者即可。

想彻底清空任务：退出程序后删除对应的 `reminders.json`，
再把旧版 `%APPDATA%\ReminderClock` 目录一并删掉，避免下次启动又被自动迁移。

> 注意：数据写在程序旁边，请把 exe 放在有写入权限的文件夹
> （桌面 / 个人文件夹 / U 盘等），不要放进 `C:\Program Files` 这类受保护目录。

## 打包成单个 exe（复制到别的电脑使用）

```bash
pip install pyinstaller        # 先装打包工具
```

然后双击项目里的 **`build.bat`**（或手动执行同款命令）。

仓库里已有打包配置 `提醒钟.spec`，等价命令也可直接：

```bash
python -m PyInstaller --noconfirm --clean 提醒钟.spec
```

打包完成后产物在 `dist\提醒钟.exe`（单文件 exe，约 18 MB，
文件名里的版本号即本次打包时刻；重新打包前请先退出正在运行的提醒钟，
否则文件被占用会写入失败）：

- 是**单文件、免安装**程序，复制到别的 Windows 10/11（64 位）电脑双击即可运行，
  目标电脑**不需要装 Python**；
- 提醒数据保存在 exe 同目录的 `reminders.json`，**连同 exe 一起拷贝就能带走
  已有任务**，互不干扰；
- 建议先发给一台测试机跑一遍（新增/编辑/到点提醒/托盘退出），确认无误再分发。

### 发布到 GitHub Releases

`dist/` 已在 `.gitignore` 中忽略，构建产物不作为源码入库，而是在
[Releases](https://github.com/lcwenjie/ReminderClock/releases) 里作为附件提供下载。
仓库内已配好 Actions 工作流（`.github/workflows/release.yml`）：

```bash
git tag v1.0.0        # 打标签，v 开头
git push origin v1.0.0
```

推送标签后会自动在 Windows 环境打包，并创建同名 Release、把 `dist\提醒钟.exe`
作为附件上传。也可以在 GitHub 的 Actions 页面手动运行该工作流（只构建、
把 exe 存为构件，不发布）。

## 目录结构

```text
main.py               # 入口：装配各模块，主线程跑 tkinter + 每秒调度
requirements.txt      # 运行依赖（仅 pystray / Pillow）
build.bat             # 一键打包脚本
提醒钟.spec            # PyInstaller 打包配置（与 build.bat 等价）
assets/
  icon.ico            # 打包使用的程序图标
core/
  __init__.py
  models.py           # Reminder 数据模型 + JSON 读写 + 存储路径/旧数据迁移
  scheduler.py        # 计算下次触发时间 + 到点判定（纯逻辑）
  version.py          # 应用版本号（以时间命名，打包时自动更新）
gui/
  __init__.py
  main_window.py      # 提醒列表主窗口（增删改 / 启用暂停）
  form.py             # 新增 / 编辑提醒的表单
  alert.py            # 置顶提醒弹窗（知道了 / 稍后提醒，延迟可改）
  tray.py             # 托盘图标与菜单（pystray）
tests/
  test_scheduler.py   # 调度算法单元测试
.github/workflows/
  release.yml         # 打 v* 标签后自动打包并发布 GitHub Release
dist/
  提醒钟.exe           # 本地打包产物（单文件 exe；不入库，走 Release 分发）
build/                # PyInstaller 构建中间文件（可随时删除）
reminders.json        # 提醒数据（运行时生成于程序目录，勿提交版本库）
error.log             # 出错时才生成
```

## 运行单元测试

```bash
python tests/test_scheduler.py     # 无需任何第三方库
# 或
python -m pytest tests/
```

## 常见问题

**启动时报“无法启动托盘图标”？**
说明缺少依赖，先执行 `pip install -r requirements.txt`。

**提醒到点没弹出？**
- 确认该提醒状态为“启用”（默认深色文字）；若显示琥珀色“已暂停”，
  选中后用工具栏“启用 / 暂停”恢复；
- 确认系统时间和提醒时间一致；
- 单次提醒如果显示灰色“已过期”，说明时间已过，请新建或编辑后使用；
- 若该行文字为红色或状态显示“配置错误”，说明提醒的时间/规则配置不合法，
  双击重新编辑修正即可。

**任务和数据存在哪里？能不能带到别的电脑？**
见上文「数据存放位置」。数据在 exe 同目录的 `reminders.json` 里，
连同 exe 一起拷到别的电脑即可带着任务继续用。

**为什么窗口点了 × 程序还在？**
设计如此：× 等于隐藏到托盘。请在托盘图标上右键选择“退出”。
